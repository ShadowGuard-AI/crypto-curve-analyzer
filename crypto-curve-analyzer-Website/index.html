A Name, a Size, an Order

The program reports elliptic curve parameters. It reports a name. It reports a key size in bits. It reports a group order, where the library exposes one. It takes one required argument: give it a curve name, or give it the path of a PEM key file. It decides which by testing whether the argument names an existing file.

Seven Named Curves, No Others

The named reels are seven, printed exactly, case included: secp256r1, secp256k1, secp384r1, secp521r1, brainpoolP256r1, brainpoolP384r1, brainpoolP512r1. Any other spelling is unsupported. A capitalised variant is unsupported. No custom curve definition can be imported.

The Key File Path

The file must hold a private key in PEM form needing no passphrase. The loader passes no password, so a protected file fails to load and the run exits 1 as an invalid key file. Results travel by log line, not by printed output: a named curve run writes nothing to standard output of its own. A key file of the wrong sort reaches the curve step and ends as an unexpected error with exit 1, its message not naming the wrong sort. Key material itself is never shown on this page; only the loading behaviour is stated.

The Note Is About the Curve, Not the Key

The controls stand in README order in the preserved record, with the restored positional first. The prime order note states a property of the named curve form, that a group of prime order has no non trivial small subgroups. It is not a test performed on the individual key. Both key file controls print a not applicable line on a named curve run.

# crypto-curve-analyzer

Reports elliptic curve parameters (name, key size, and group order) for one of seven named curves or for the curve of an operator supplied PEM key file. With a key file it can also report a prime order note for that curve and write out the public key. It does not produce a weakness verdict and does not import custom curve definitions. - Focused on Basic cryptographic operations

## Install

`git clone https://github.com/ShadowStrikeHQ/crypto-curve-analyzer`

## Usage

`./crypto-curve-analyzer [params]`

## Parameters

- `-h`: Show help message and exit

- `--verbose`: Enable verbose output for debugging.

- `--check-small-subgroup`: Report the prime order note for the curve of a PEM key file. Requires a key file; not applicable on a named curve run without one.

- `--output-public-key`: Output public key in PEM format to the specified file. Requires a key file; not applicable on a named curve run without one.
